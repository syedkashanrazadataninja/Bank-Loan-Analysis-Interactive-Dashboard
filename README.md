Project Overview

An interactive Power BI dashboard developed to analyze bank branch performance across regions, branches, and time periods. The dashboard converts raw banking data into a structured and interactive reporting solution for monitoring financial and operational performance.

Key Features

>Interactive KPI dashboard covering deposits, loans, revenue, expenses, profit, and customer performance
>Branch-wise and region-wise performance analysis using charts and visual comparisons
>Monthly trend analysis for deposits and loans
>Geographic visualization of branch performance using map visuals
>Interactive slicers for filtering by region, branch, month, and other dimensions
>Designed a Star Schema using Fact and Dimension tables for efficient data modeling
>Cleaned, transformed, and prepared raw data using Power Query

Tools & Skills

Power BI Desktop | Power Query | DAX | Data Modeling | Star Schema | Data Visualization

Project Workflow

Raw Data → Data Cleaning → Data Transformation → Data Modeling → KPI Development → Interactive Dashboard
